# 🍪 Doce Mordida - Website

Bem-vindo ao repositório do site **Doce Mordida**, uma confeitaria artesanal especializada em biscoitos de amendoim e cookies recheados.

## 📂 Estrutura do Projeto

Para garantir compatibilidade máxima, todos os arquivos estão na raiz:

```
Doce Mordida/
├── index.html                    # Página principal
├── logo.png                      # Logo
├── biscoito-branco.png           # Imagens de produtos
├── carousel-1.png                # Imagens da galeria
└── ...                           # Todas as outras imagens
```

## 🚀 Como Rodar Localmente

1. **Clone ou baixe** este repositório.
2. Abra o arquivo `index.html` em seu navegador.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3**
- **Bootstrap 5**
- **JavaScript**
